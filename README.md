# Project Portfolio V2

A modern, responsive developer portfolio built with React, TypeScript, and Vite.

## ✨ Features

- Modern single-page portfolio
- Responsive design for desktop and mobile
- Animated Home, About, Projects, and Contact sections
- Interactive project carousel
- Project screenshots and technology details
- Resume download
- GitHub and LinkedIn integration
- Contact section
- Smooth UI animations

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React
- Three.js
- React Three Fiber

## 📂 Main Sections

### Home
Introduction, role, resume download, and social links.

### About
Technical skills and development tools.

### Projects
Interactive project showcase with project details, technologies, GitHub repository, and live demo.

### Contact
Contact form and personal contact information.
